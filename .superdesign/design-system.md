# Paper Studio design system

Paper Studio is a practical JEE question-paper workspace for educators. It should feel focused, reliable, and operational—not like a marketing product.

Use Inter only. Preserve the existing color system: navy navigation (#172a45), blue primary actions (#1769e0), white cards, and the light blue-gray canvas. Use compact 8px buttons, 10–13px cards, light borders, and restrained shadows. Never add gradients, decorative illustrations, serif fonts, purple/pink colors, or invented branding.

Dashboard direction: a command center with a slim navy navigation rail, a concise heading and quick actions, metric cards, live generation activity, and a scannable paper-card library with search, filters, statuses, and contextual actions. Keep information density high but approachable. Make desktop content use a max-width workspace and adapt to a single-column mobile layout with horizontal controls.
